# 📡 TelecomAI Assistant

An intelligent AI-powered telecom business analytics dashboard built with Python, Machine Learning, and Large Language Models.

## 🎯 Project Overview

TelecomAI Assistant is a complete data-driven web application that helps telecom companies:
- Predict customer churn using Machine Learning (80% accuracy)
- Recommend the best data packages for each customer
- Analyze bundle purchase patterns and app usage trends
- Answer any business question through an AI chatbot powered by Llama 3
- Generate automated business reports from real telecom datasets

## ⚙️ Installation & Setup

### Step 1 — Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/telecom-ai-assistant.git
cd telecom-ai-assistant
```

### Step 2 — Create Virtual Environment

```bash
python -m venv .venv
```

**Activate on Windows:**
```bash
(Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned) ; (& .\.venv\Scripts\Activate.ps1)
```

**Activate on Mac/Linux:**
```bash
source .venv/bin/activate
```

### Step 3 — Install Dependencies

```bash
pip install pandas numpy scikit-learn joblib streamlit plotly groq python-dotenv openpyxl reportlab
```

### Step 4 — Get Free Groq API Key

1. Go to **console.groq.com**
2. Sign up with Google account (free — no credit card needed)
3. Click **API Keys** → **Create API Key**
4. Copy the key (starts with `gsk_...`)

### Step 5 — Create .env File

Create a file called `.env` in the project root:
GROQ_API_KEY=gsk_your_real_key_here

### Step 6 — Add Dataset Files

Download the IBM Telco Customer Churn dataset from Kaggle:
- Search: **"Telco Customer Churn"** on kaggle.com
- Download `WA_Fn-UseC_-Telco-Customer-Churn.csv`
- Rename it to `telecom.csv`
- Place it inside the `data/` folder

### Step 7 — Train the ML Models

```bash
python model_builder.py
```

This creates all 5 model files inside the `models/` folder.

### Step 8 — Test the Connection

```bash
python test_groq.py
```

You should see: `✅ Groq is working!`

### Step 9 — Run the Application

```bash
streamlit run app.py
```

Open your browser at: **http://localhost:8501**
